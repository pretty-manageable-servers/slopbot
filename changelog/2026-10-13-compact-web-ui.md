- Smaller headers, headings, forms and message spacing across the console, with a two-column settings layout on wide screens.
- Mobile conversations open in an overlay drawer with keyboard focus handling. The chat follows the visible viewport when the keyboard opens.

- Improved light-theme contrast, visible keyboard focus, touch targets and dialog sizing.
