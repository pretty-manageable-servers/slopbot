# Categorized memories and memes

Slopbot's existing memory tools now support facts, memes, preferences, lessons, and notes, with tags and structured details. Search can filter categories and tags or find an entry by a situation.

Memes can keep an optional media link, aliases, usage guidance, and an explanation of the joke. They default to independent memories, so saving one does not require a media upload or saved source message. Channel and server boundaries still apply.

You can update your memories using their current revision. Forgetting one no longer removes its source message or other memories that share that source. Existing memories remain source-bound facts.
