# Show confirmed tool outcomes and task memory scopes

Completed-reply tool counts include only confirmed completions. Unfinished calls show an unknown outcome. When a run is interrupted before a result is recorded, its failure notice and activity identify the unconfirmed call and tell the user to inspect the action journal before retrying writes.

Parent-channel memory listings identify separate task-thread memory scopes and link to threads the requester can access. Thread memory contents remain in their original scope.
