# Readable reply pages and live tool calls

Long Discord replies keep sentences together when they fit on a page. Oversized sentences split at word boundaries, and code lines stay together when possible while code fences remain balanced.

Programmatic tool runs now show their individual tool calls in a grouped, monospace status block. Calls update as they run, complete, fail, or get blocked, with durations and totals for each run. Long histories show recent calls and prioritize active calls, with the rest available in the tool trace.
