### Investigation and issue reporting
- Slopbot can inspect reported interactions, its actual deployment pipeline, GitHub CI and allowlisted PMServers services.
- Selected evidence becomes a GitHub issue or a comment on an existing issue, with reproduction details and an acceptance check. Interrupted writes reconcile before retrying.
- Issue watches follow fixing PRs and deployments, and record behavioral observations against fresh evidence. Coding agents still implement fixes.
- Operational access requires an explicit server allowlist and dedicated credentials. Reports exclude raw prompts, reasoning and tool arguments, and recheck source access before publication.
