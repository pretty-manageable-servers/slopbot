### Console views, settings dialog and command menu
- Two views in the top bar: Chats (your private chats) and Servers (Discord server channels and threads, with the server picker).
- Settings opens as a dialog from the profile menu. It is full screen on mobile.
- Cmd+K or Ctrl+K opens a command menu: actions, chats, channels, servers and message search with formatted snippets.
- Fuzzy message search: typos, partial words, any word order. The sidebar box filters the list as you type.
- Mobile: the conversation drawer slides in, and the new chat composer sits at the bottom of the screen.
- The greeting and account menu use your Discord name, not the server nickname.
- Shared conversations render formatted text and look like the chat. "Continue in Slopbot" copies a share into a new private chat. Images are not copied.
- Fixed the code block language label style.
